# Studium v0.5.1: the plan

Scope set by the operator on 2026-11-05, right after v0.5.0 went live:

- The road from raw material to the knowledge graph and its question banks must work without fault, for any file,
  handwriting included.
- The map needs many more controls.
- The Draconic Knowledge Hub (in `private/`, 463 files, 4.9 GB, 28 courses) is uploaded under his account, in
  batches.

**Order of work.** The features and the pipeline come first. Only then is the hub uploaded, batch by batch, with
Studium's own tools. Each batch is checked in the map before the next one, so a problem is fixed before much data
depends on it.

## 1. One standard for what the graph learns (contribution v2)

v1 contributions keep working; v2 adds what the routes and the question banks need.

- **Stage.** Which evaluation the material belongs to: «Parcial 1», «Examen 2», «Final», «Quiz 3», «Deber 4». It is
  normalized into a kind and a number, and placed on the course's timeline. A question can name its own stage when one
  file holds several exams.
- **Order and units.** Concepts come in the order the material teaches them, with the unit, chapter or week when the
  material shows it.
- **What comes first.** Each concept says what must be known before it (`needs`). The first batches showed that
  «related … prerequisite» was read both ways by an AI, so prerequisites have their own field; `related` keeps
  part, uses, example, contrast and related, read «this concept, relation, the other one».
- **Aliases.** Each concept has one short standard name in Spanish, plus its other names (English, abbreviations).
  - A name in parentheses becomes an alias: «Búsqueda en anchura (BFS)» is «Búsqueda en anchura», alias «BFS».
  - The map joins concepts by name, by alias, and regardless of plurals («Subred» and «Subredes» are one concept).
- **New kinds:**
  - «Sílabo o programa»: units, weeks, and which evaluation covers what. This is the official route of a course.
  - «Práctica o laboratorio».
  - «Resumen o formulario».
- **Source.** A contribution may say it comes from a registered collection, such as the Draconic Knowledge Hub, which
  gets the credit. Never a file name: file names carry students' names.
- **Fingerprint.** A hash of the original file, so the same file is never added twice.
- **Terms.** USFQ term codes read the same everywhere: «202610» is «1.er semestre 2026-2027».

## 2. Any file, read in the browser

`files.js` turns whatever a person drops into parts their AI can read, and nothing leaves the browser except toward
their AI.

| File | Handling |
| --- | --- |
| Short PDF (scanned or not) | One part. |
| Long PDF | Split by its chapters (its outline) or in windows of pages. For a book, its table of contents first; chapters on request. |
| Photos | Shrunk to a size every provider accepts. Pages of the same exam can be joined into one material. |
| Word, PowerPoint, Excel, OpenDocument, EPUB | Unzipped and read in the browser: text per page, slide, sheet or chapter, plus a few figures. |
| Jupyter notebooks, code, text, Markdown, LaTeX, CSV | Text, in parts when long. |
| ZIP | Each file inside is handled as above. |
| Video and audio | Skipped, with a clear reason. |

Around the parts:

- **The queue** shows every part, the result of each, and «Publicar todo lo listo» for the items with nothing
  personal to check.
- **Without an API key**, Studium prepares the parts for a person's subscription: it downloads the prepared files and
  copies the instructions for claude.ai, ChatGPT or Gemini.

## 3. A map that scales and does much more

### The engine

- Barnes-Hut repulsion.
- A layout that settles across frames instead of blocking.
- Islands by course, placed by subject area.
- Culling and level of detail.
- A label grid.

Target: thousands of concepts stay fluid.

### Controls

- **The toolbar.** Under the menu, aligned with it, reserved for search, filters, views, routes and questions.
  «¿Para qué sirve?» and «Créditos» move to the corner, like a map's attribution. The course legend goes away: it only
  worked with four courses.
- **Filters.** A drawer: courses (searchable), professors, academic terms, «hasta» an evaluation, sources, kinds of
  material, and «solo mis materias e intereses» (from the profile). Active filters show as removable chips.
- **Selection.**
  - Click selects one; Shift or Ctrl adds or removes; Shift-drag selects a box.
  - Then: select neighbours, the whole island, invert, hide, show only this, a route to here, or a guide with this.
- **Views:**
  - The views that light up nodes:
    - how it grew (kept);
    - most asked;
    - difficulty;
    - bridges between courses;
    - what you grew (your guides and contributions);
    - what you still lack (concepts you have not marked as known);
    - gaps (mentioned, never explained);
    - recent;
    - by professor.
  - The views that lay the map out differently: the course timeline (evaluations as columns) and the curriculum.
- **Routes.**
  - A route is a course plus an evaluation, with a professor and a term if wanted, for example Examen 2 of Redes. It
    gathers that evaluation's concepts and everything they need before them, across courses, and stops there: what
    belongs to Examen 3 stays out.
  - It is drawn from the foundations at the bottom up to the evaluation.
  - Its panel lists every step with its questions.
  - «Crear una guía con esta ruta» opens the guide form already filled in: course, evaluation, professor, term, the
    map as the source, and exactly the route's concepts. A guide can be made without one's own material, or with it.
- **Ask the map.** In words: «muéstrame la ruta para rendir el Examen 2 de redes». With the person's AI connected, the
  AI reads a compact index of the map and answers with an action that Studium carries out. Without an AI, a simple
  reader of common phrasings does the same for routes, courses, concepts and «entre A y B».
- **Also:**
  - the path between two concepts;
  - focusing a neighbourhood;
  - materials and syllabi as their own nodes, and in the course panel;
  - «Ya lo sé» on each concept.

## 4. The profile

- My courses this term.
- Interests and hobbies.
- Concepts I already know.

All optional. The map uses the first two to hide islands, the third for «what you still lack».

## 5. Reads that stay within the free plan

Today every visit downloads every contribution: one read each. With the hub, that would spend the free quota within
weeks of growth. Instead:

- **Packs.** A few documents hold all public contributions, compiled on demand by an admin from the panel, and by
  the upload tool after a batch.
- **The browser** keeps them in IndexedDB and only reads what changed after the last pack.
- **Removals.** An owner who deletes a contribution or makes it private leaves a removal record, so it disappears
  from every map at once.
- **Admin hiding.** It recompiles.

## 6. Updates that reach everyone

The portfolio serves `/studium/assets/*` as immutable for a year, under the same names in every version, so a
returning visitor can keep old code. The release now puts the assets under a versioned folder.

## 7. The hub, in batches

- **The operator's account.** The upload runs with the operator's account, through Studium's own pipeline, in a
  browser: intake, instructions, review, the personal-data check, publishing. The AI in the loop is Claude, answering
  exactly what Studium asks; no API key leaves this computer.
- **Credit.** Every contribution names the Draconic Knowledge Hub as its source, and no file names are kept.
- **Batches.** Each batch is checked in the map before the next, starting with Redes. Every batch runs first against
  the local preview, then in production after the release.
